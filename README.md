Currently configured for basic front-end use, including Python, Prolog, and Clingo-based solving.

To start:

Backend:
``` 
uvicorn backend.main:app --host 127.0.0.1 --port 8080
```

Frontend:
``` 
cd web-interface
npm install 
npm start
```

To test solvers
```
python scripts/test_solvers.py
```
